# SENSE — Notebooks Index

This directory contains Jupyter notebooks for exploratory data analysis, experiment visualization, hyperparameter sweeps, and final thesis reporting.

Per `Final_plan.md`, individual notebooks are created in their respective project phases:

- `00_data_exploration.ipynb` — Created in **Phase 2 (P2.0/P2.7)**: Dataset exploration, class distribution, stereo pair visual QA.
- `01_enhancement_qa.ipynb` — Created in **Phase 3 (P3.6)**: Visual QA of FUnIE-GAN and WaterNet enhanced images across scenarios.
- `03_baseline_experiment_analysis.ipynb` — Created in **Phase 4 (P4.4)**: Inception/GoogleLeNet baseline evaluation & error analysis.
- `05_hyperparameter_analysis.ipynb` — Created in **Phase 7 (P7.5)**: Hyperparameter sweep analysis & unfreezing schedule plots.
- `06_final_evaluation.ipynb` — Created in **Phase 8 & 11 (P8.4/P11.4)**: Experiment 1 evaluation & comparative analysis vs DARE / VT-UHGR.
- `07_robustness_analysis.ipynb` — Created in **Phase 9 (P9.5)**: Leave-One-Scenario-Out (LOSO) cross-scenario difficulty ranking & statistical analysis.
- `04_ablation_study.ipynb` — Created in **Phase 10 (P10.5)**: Enhancement, stereo vs. mono, and text-guidance ablation study analysis.
