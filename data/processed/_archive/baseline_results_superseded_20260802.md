## Checkpoint Selection Note

The Phase 4 baseline checkpoint (`checkpoints/baseline_best.pth`, epoch 17) was selected by
**best validation accuracy** (97.04 %), because the Phase 4 training loop
(`scripts/train_baseline.py`) logged accuracy only — not macro F1-score.

This is a **documented deviation** from the project Evaluation Strategy, which specifies
validation macro F1 as the primary checkpoint-selection criterion (with min-class accuracy as a
tie-break). The deviation is acceptable because Phase 4 is a pipeline-correctness gate
(verifying the data pipeline is non-trivially accurate), not the headline model result.

**The Phase 4 numbers in this file are the sanity-check record only.** The final comparison
table entry (P11.1) for the ResNet18 baseline must be produced by re-running
`configs/baseline_transfer_learning.yaml` through the Phase 6 Trainer infrastructure with
macro-F1 checkpoint selection (optionally 3 seeds, reported as mean ± std).
