## 2. Checkpoint selection

| Epoch | Validation macro F1 | Validation accuracy | Minimum class accuracy | Validation loss |
|---:|---:|---:|---:|---:|
| 17 | 0.944755 | 0.966734 | 0.708333 | 0.112997 |
| 19 | **0.942009** | **0.965517** | **0.791667** | **0.116726** |

Epoch 17 held the highest single-epoch macro F1, but its minimum class accuracy
was 0.708333. Epoch 19 fell inside the 0.005 tie window
(0.944755 − 0.942009 = 0.002746) with a minimum class accuracy of 0.791667, so
the tie-break selected epoch 19. The selected checkpoint is therefore epoch 19.

This is the selection rule operating as designed, not an anomaly. The
`max_macro_f1_seen` field stored in the checkpoint is 0.944755, which is the
epoch-17 peak, not the selected value.
